Our approach to accessibility and how to report a problem.

<!--more-->

{% include content/section.html do="start" color="cool" %}

The ARK Alliance is committed to making this website accessible to people with
disabilities. We are working toward meeting the
[Web Content Accessibility Guidelines (WCAG) 2.1](https://www.w3.org/TR/WCAG21/)
at Level AA and continue to review and improve the site's accessibility.

## Report an accessibility problem

If you encounter an accessibility barrier or need information in another format,
please email [{{ site.contact.email }}](mailto:{{ site.contact.email }}).
Include the page address and a description of the problem. If relevant, tell us
which browser or assistive technology you are using so we can investigate.
